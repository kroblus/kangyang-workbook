# 康养工作簿 V1

给养老顾问使用的单人、单设备离线工具。四个主入口：工作台、单位、客户、活动。无登录、网络调用、广告、分析或 AI 请求。

单位/客户是长期档案，联系人和服务对象是独立角色；每次拜访或沟通单独保存。临时速记可以没有对象，以后编辑补充关联。姓名可重复，电话不必填，不自动判断单位性质、决策权、合作意向或健康情况。

工作台区分今日、逾期、未来和未设日期待办。日期型任务当天结束前不过期，开启提醒时默认09:00；所有业务日期以 Asia/Shanghai 计算。活动提醒默认关闭，改期不会平移独立筹备事项，取消活动可选择保留或取消关联未完成待办。

自动草稿短延迟写入本机，显示“草稿已保存”后才表示落盘。可以离开表单后从工作台继续。正式提交保留原有标识，不重复生成跟进任务。单位客户采用归档，历史记录和待办保留。

照片通过系统照片选择器，文件通过系统文件选择器导入，复制到私有目录后使用。支持图片、PDF、Office、文本和 CSV，单文件20 MB。缺失或损坏附件不会被伪称可用。

对外导出可按日期和对象筛选，默认不含详细正文或联系人电话、照护信息。正文可能含自由填写的个人信息，请检查预览后主动勾选。CSV 带 UTF-8 BOM，转义引号/换行，并防止公式前缀；导入表格软件时电话等列仍需选“文本”。

完整备份采用口令加密，可在另一设备恢复。口令无法找回。恢复先预检、再确认完整替换，并保留一次本机回滚快照。附件总量64 MB；旧内容寻址附件会为回滚保留，暂未提供清理功能。

不包含：云同步、多人协作、AI、录音、微信聊天读取、营销群发、合同收款、库存、复杂报表。谈判记录不是合同，照护备注不是医疗诊断。

应用内名称可在本人资料修改；Android 桌面安装名称固定为“康养工作簿”。本人电话和二维码由使用者自行填写/选择，未写入测试常量。
