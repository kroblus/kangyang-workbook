# 给朋友的10分钟试用

1. **第1分钟：打开工作簿。** 首次没有客户记录，不需注册。右上头像可修改本人资料、业务标签和应用内名称。本人电话、微信二维码按需自行添加。
2. **第2分钟：建立单位。** 点底部“单位”→“新增单位”，填名称与类型即可保存。主体性质不确定就保留“暂不清楚”。保存后可添加多位联系人。
3. **第3分钟：记一次拜访。** 单位详情点“记一次拜访”，写重要内容。下一步填写“发送服务方案”，跟进日期可选三天后。保存后这次记录会留在时间线。
4. **第4分钟：看跟进。** 工作台点“全部待办”→“未来”。找到刚才的跟进；可以完成、取消、重新打开、改期。没定日期的事项在“未设日期”。提醒需主动开启并允许系统通知，可能延后。
5. **第5分钟：建立客户。** “客户”→“新增客户”，称呼可写某某家庭。保存后分别添加联系人和服务对象，例如女儿是联系人，母亲是服务对象。器具或培训咨询不必填老人入住资料。
6. **第6分钟：安排活动。** “活动”→“新增活动”，填起止时间、地点、方案与物料；保存后添加筹备待办。改期时检查独立日期的待办。取消活动可选择保留还是取消未完成待办。
7. **第7分钟：使用草稿。** 工作台点“记一笔”→“临时速记”，输入几行内容，等“草稿已保存”后返回。工作台的“继续草稿”可接着写。正式保存不会重复生成记录。
8. **第8分钟：查找历史和照片。** 点右上搜索，输入单位、联系人、电话或关键词。进入详情可看时间线与附件。照片和文件导入后已复制到本机，通常无需保留原位置。
9. **第9分钟：导出。** 头像→“导出与分享”，选择日期和对象，检查范围与预览。正文和个人信息默认不勾选。可保存CSV或自己选择系统分享接收方。CSV不是完整备份。
10. **第10分钟：做完整备份。** 头像→“完整备份与恢复”，设置至少8个字符的口令并确认，选择文件保存位置。记住口令，无法找回。换机恢复时输入原口令、选择备份、核对预览后确认完整替换。先备份新手机已有内容。

当前交付为测试签名APK。安装升级请使用相容签名的新包覆盖安装，不要随意卸载（卸载会删除本机资料）。朋友实际手机尚未测试；本轮模拟器结果和限制见 ACCEPTANCE.md。
