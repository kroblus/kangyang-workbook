# 姜宏的 V1.1 简短试用说明

先用一条普通工作内容试试看，不必先建档案。

1. **想起来就记。** 打开工作台，点一次“记一笔”，直接写：“周院长希望先看服务介绍，下周再联系。”不用先填标题、对象和时间。
2. **直接返回，内容还在。** 写好后点返回或“完成”，应用会先保存当前内容；工作台“最近记录”和右上角搜索都能找回。看到“已保存”表示文字已经存好。若提示“未保存，点击重试”，请点提示重试后再离开。
3. **后来补对象。** 打开记录点“编辑”→“关联”，搜索单位或客户并选择。暂时不清楚是谁也可以不关联。补记昨天的谈话时，点记录日期改成昨天。
4. **想好下一步再加跟进。** 点“加跟进”，写“发送服务介绍”，选明天，点“加入跟进”。工作台会列出需要处理的事项。完成后点勾；改期只改跟进，不会改谈话发生时间。提醒需要自己打开，系统可能延后。
5. **照片和方案也能留下。** 记录中点“附件”，选择照片或文件，等提示导入成功。每个文件最多20 MB；只有附件也能留作记录。进入一条已有记录后清空正文，会保留一条可以继续写的“空白记录”。
6. **活动日期没定，也能先保存。** “活动”→新增，填写名称和方案，以“筹备中／时间待定”保存。确定日期后再补起止时间；筹备跟进可以分别安排。
7. **定期留备份。** 右上头像→“备份资料”，设置至少8个字符的口令，再输入一次，保存文件。口令无法找回，请另外记好。换手机时进入“从备份恢复”，输入原口令、选择文件，检查内容后确认。恢复会替换手机中现有的全部工作资料，先把当前资料也备份一份。

单位、客户、联系人和服务对象仍可随时补充。旧版本尚未完成或需要检查的内容，可在工作台的“待整理的填写”里继续找。导出 CSV 或文本适合对外提供记录，不能代替完整备份。

安装更新请直接覆盖原应用，不要先卸载。当前是试用安装包；朋友实际手机的试用情况与模拟器测试分开记录，详见 [验收报告](ACCEPTANCE.md)。
